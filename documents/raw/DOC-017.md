# Quality Inspection Procedure: Plant P002 Batch Audit
Document ID: DOC-017 | Version: 3.0 | Effective: 2024-04-22
Facility: Plant P002 | Department: Quality Assurance

## 1. Inspection Criteria
All production orders (such as PO-00102) produced at Plant P002 must undergo 100% automated dimensional and surface inspection.

## 2. Defect Classification
- Surface Finish Defect: Ra > 0.8 µm (Triggered by machine vibration on M041)
- Dimensional Non-conformance: ±0.05 mm tolerance limit
- Coating Failure: Adhesion test fail

## 3. Corrective Action Procedure
If defect count exceeds 5 parts per batch:
1. Halt production line L001.
2. Inspect tooling on M041.
3. Log Quality Event QE-00102 in the enterprise context engine.
